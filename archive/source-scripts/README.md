# Original source scripts

These scripts preserve how the earlier report, benchmark, guide, terminal capture, replay, and workflow checks were produced. They retain original absolute paths and environment-specific dependencies. They are provenance records, not a portable installer or a promise of one-command regeneration.

The current repository checks in scripts/ are portable. The original capture began after initial source review and initialization; the replay renderer creates chapter cards from that authentic terminal stdout. It does not create live interface footage.
