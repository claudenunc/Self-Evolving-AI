# Preserved workflow sources

These five folders are copies of the user's installed workflows at the time of export:

| Workflow | Purpose |
| --- | --- |
| Evidence Research | Research consequential questions with checked evidence |
| Decision and Experiment | Compare options and choose a small informative test |
| Verified Execution | Complete an authorized result and verify it |
| Research to Implementation | Carry out useful recommendations from a reviewed plan |
| Teach and Repeat | Document real work and preserve a reusable process |

The copies contain SKILL.md, metadata, icons, and any supporting references. The repository preserves their sources; it does not automatically install or activate them in a new account. Platform-specific references in the files describe their original supported runtime. Use the platform's current installation workflow when reusing them.
